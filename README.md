# E-commerce Store - Webáruház Projekt

Ez egy teljes körű (Full-stack) webáruház alkalmazás, amely a gyorsaság és hatékonyság érdekében egyedi fejlesztésű megoldásokat használ keretrendszerek nélkül.

## 🌐 Élő bemutató (Live Demo)
Az alkalmazás az alábbi címen érhető el:
http://fagravir.fagravir.nhely.hu/

## ✨ Főbb funkciók
- **Dinamikus termékkezelés:** Termékek listázása és megjelenítése JavaScript segítségével.
- **Interaktív kosár:** Termékek hozzáadása, darabszám módosítása és a végösszeg automatikus kalkulációja.
- **Reszponzív felépítés:** Mobilra és asztali gépre optimalizált megjelenés tiszta CSS segítségével.
- **Backend logika:** PHP alapú szerveroldali feldolgozás.
- **Adattárolás:** Strukturált SQL adatbázis a termékek és adatok biztonságos kezeléséhez.
- **Kezelőbarát felület:** Gyors betöltés és egyszerű navigáció.

## 🛠️ Felhasznált technológiák
- **HTML5:** A weboldal szerkezeti felépítése.
- **CSS3:** Egyedi stíluslapok a vizuális megjelenésért.
- **JavaScript:** A dinamikus funkciók és a kosár logika kezelése.
- **Backend:** PHP
- **Adatbázis:** SQL (MySQL)
- **Tárhely:** nhely.hu

## 📝 Megjegyzés
A projekt célja a tiszta webes technológiák (HTML/CSS/JS) hatékony alkalmazásának bemutatása egy webshop környezetben.
